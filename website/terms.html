2. Description of Service

Fast Send is an event and trip photo-sharing service designed to simplify how event memories are delivered:

  • Organizer App (Android): Enables trip organizers, tour guides, and event planners to create trips, customize privacy options, generate dynamic QR codes, and batch-upload event photos.
  • Guest Web Portal: Enables event attendees to register with their name and reference selfie, browse face-matched event photos, view trip statistics, and download full-resolution streaming ZIP archives without installing an app.
  • AI Matching Pipeline: Automated cloud systems that detect human faces, calculate vector embeddings, and match photos based on facial similarity.
