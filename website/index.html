Deep Dive

Engineered for Scale and Simplicity

Fast Send is powered by a synchronized trio of modern mobile, cloud AI, and web systems.

Pillar 1: Organizer App

Built with React Native & Expo

The official organizer application features a custom Neobrutalist design system with full Light and Dark mode adaptation.

  • ✓ Dynamic QR Code Generation: Instant sharing for live events.
  • ✓ Duplicate Trip Protection: Enforces unique event naming per organizer.
  • ✓ Trip Archive & Search: Instantly filter past trips by name or invite code.
  • ✓ Real-time Notification Center: Track uploads, guest registrations, and photo matches.
  • ✓ Granular Trip Settings: Toggle guest permissions to download nature photos or all event media.

⚡ Mobile Tech Stack (frontend3)

• Framework: React Native 0.81 + Expo SDK 54 • Router: Expo Router v6 (File-based routing) • Auth: Google Firebase Authentication • UI: Custom Neobrutalism Design System • Icons: Lucide Icons & Custom SVG Assets • Engine: Hermes JS Engine with Edge-to-Edge display
Pillar 2: AI & Cloud Pipeline

High-Concurrency Face Matching

The backend pipeline processes photos in parallel without degrading server performance or buffering huge files into RAM.

  • ✓ InsightFace 512-D Vectors: Extracts high-precision facial embeddings via ONNX runtime.
  • ✓ Smart Photo Tagging: Classifies assets into solo portraits, group photos, and nature landscapes.
  • ✓ Direct Azure Streaming: Generates time-limited SAS tokens for zero-RAM memory streaming.
  • ✓ Celery Distributed Tasks: Asynchronous background photo indexing backed by Redis.
  • ✓ HEIC & RAW Decoding: Full cross-platform image compatibility via Pillow-HEIF.

🧠 AI & Cloud Stack (backend)

• Web Framework: FastAPI (Asynchronous Python 3.11) • Database: MongoDB with Beanie Async ODM & Motor • Task Worker: Celery + Redis message broker • Face Engine: InsightFace / Buffalo_l model • Cloud Storage: Microsoft Azure Blob Storage (SAS) • Streaming: Zipstream-ng for zero-RAM memory streams
Pillar 3: Guest Web Portal

Zero-Install Browser Experience

Event guests never have to install an app from the app store. They simply tap the link or scan the QR code to access their personalized event portal.

  • ✓ Instant Browser Access: Works across iOS Safari, Android Chrome, and desktop.
  • ✓ Smart Filter Tabs: Switch between "My Photos", "Group Photos", and "Nature & Scenic".
  • ✓ AI Trip Insights Card: Shows download size, solo photo count, and "Most Seen With" friend.
  • ✓ High-Speed ZIP Download: Download all matched photos in one packaged archive.
  • ✓ Tokenized Security: Guest tokens strictly limit access to the designated event only.

🌐 Web App Stack (guest-web)

• Framework: Next.js (App Router) + React • Deployment: Vercel Global Edge Network • Styling: Responsive Tailwind CSS • Camera: Web MediaDevices API for instant selfie capture • Download: Chunked streaming blob downloads
